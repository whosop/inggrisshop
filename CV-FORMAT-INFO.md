# 📄 Format CV Baru

## File CV Baru: `cv-new.html`

Saya telah membuat tampilan CV baru yang mengikuti format professional modern seperti yang Anda minta dengan fitur:

### ✨ Fitur Utama:

1. **Layout Modern & Clean**
   - Format satu kolom yang mudah dibaca
   - Header dengan foto di samping kiri dengan background biru gradasi
   - Nama besar dan bold di sebelah foto
   - Contact info yang terstruktur

2. **Struktur Konten:**
   - **ABOUT ME** - Deskripsi profesional
   - **EDUCATION** - Riwayat pendidikan dengan format bullet dan tanggal italic
   - **INTERNSHIP/ORGANIZATIONAL EXPERIENCE** - Pengalaman organisasi dengan detail
   - **PROJECT EXPERIENCE** - Project yang pernah dikerjakan
   - **ADDITIONAL INFORMATION** - Skills dan sertifikasi

3. **Tombol Download CV** 🎯
   - Tombol gradasi biru yang menarik
   - Icon download
   - Ketika diklik, akan membuka dialog Print
   - User bisa "Print to PDF" untuk save CV sebagai PDF

4. **Print-Friendly**
   - CSS khusus untuk printing
   - Navbar dan footer disembunyikan saat print
   - Format tetap rapi saat di-print atau save as PDF

### 🎨 Design Features:

- **Foto Box**: Kotak biru gradasi (180x220px) dengan foto di dalamnya
- **Typography**: 
  - Nama: 2.5rem, extra bold
  - Section titles: uppercase, bold, dengan garis pembatas
  - Content: font size 0.9-0.95rem untuk readability
- **Layout**: Max-width 900px, centered, dengan padding dan shadow
- **Colors**: 
  - Primary: Navy blue (#1e3a8a)
  - Text: Dark slate (#1e293b)
  - Light text: Slate (#64748b)

### 📱 Responsive:
- Mobile-friendly
- Stack layout untuk layar kecil
- Foto dan info tetap readable di mobile

### 🔗 Navigation Update:
Semua halaman (index, about, skills, portfolio) sudah di-update untuk mengarah ke `cv-new.html`

### 💡 Cara Download CV:
1. Klik tombol "Download CV"
2. Dialog Print akan muncul
3. Pilih "Save as PDF" atau printer
4. CV akan tersimpan dalam format PDF yang professional
