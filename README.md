# 💼 Shofiyatul Nur Ghilbah - Professional Portfolio Website

A modern, professional **single-page** personal branding website showcasing skills, projects, and professional experience with clean design principles and smooth scrolling navigation.

## 🎨 Design Philosophy

This website features a **professional single-page design** with:
- **One-Page Layout**: All content accessible through smooth scroll navigation
- **Clean & Modern Layout**: Minimalist design with structured spacing and organized content
- **Professional Color Scheme**: Navy blue (#1e3a8a), sky blue (#0ea5e9), and amber (#f59e0b) for a corporate look
- **Typography**: Inter font family for clean, professional, and readable text
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- **Smooth Scrolling**: Seamless navigation between sections with active indicators
- **Business-Ready**: Suitable for professional networking and job applications

## ✨ Features

- **Single-Page Navigation**: All content in one page with smooth scroll
- **Active Section Indicator**: Auto-highlight current section in navbar
- **Responsive Navigation**: Fixed navbar with smooth scrolling and mobile hamburger menu
- **Multi-language Support**: English and Indonesian language switching
- **Hero Section**: Professional introduction with clear call-to-action buttons
- **Skills Showcase**: Visual representation of technical and soft skills
- **Projects Portfolio**: Project showcase with image sliders and detailed descriptions
- **Professional CV**: Clean, structured curriculum vitae with print functionality
- **Social Integration**: Professional links to GitHub, Instagram, and email

## 📦 Installation & Usage

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Navigate through sections using the navbar or by scrolling
4. Switch language using the globe icon
5. Download CV by clicking the "Download CV" button in CV section

```bash
# Simply open in browser
open index.html
# or
start index.html
```

### Navigation
- Click navbar menu items to scroll to sections
- Or scroll manually - the active section will be highlighted automatically
- Mobile: Use hamburger menu for navigation

### Download CV
- Scroll to CV section (#cv)
- Click "Download CV" button
- Use browser print dialog (Ctrl+P / Cmd+P)
- Save as PDF for professional use
